# Sehar Tariq — Animated CV Portfolio (Website 1)

A responsive single-page, **scroll-enabled** portfolio built with HTML, CSS and JavaScript. It works on laptops, tablets and phones.

## Run locally

Open `index.html` in a browser. For a development server, use VS Code's **Live Server** extension or run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Upload to GitHub

Create a new GitHub repository, open a terminal in this folder and run:

```bash
git init
git add .
git commit -m "Add Sehar Tariq portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sehar-portfolio.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. To publish free using **GitHub Pages**: open repo **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.

## Deploy on Vercel

1. Push all project files to a GitHub repository.
2. Sign in at https://vercel.com with GitHub.
3. Choose **Add New → Project** and import your repository.
4. Use **Framework Preset: Other** (plain HTML/CSS/JS). Leave build command blank and output directory at the project root.
5. Click **Deploy**. After deployment, copy the production URL ending in `.vercel.app` and submit that URL.
